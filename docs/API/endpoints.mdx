Choose the API reference that matches your version of MCSS:

## API v2 (Current — MCSS 13.7+)

Use **API v2** for all current MCSS installations (including MCSS 13.10.0). It provides full support for server control, console streaming, backups, scheduled tasks, webhooks, user management, and API keys.

- **[Browse the API v2 Endpoint Reference](/apis/v2)** — Interactive documentation for every v2 endpoint, organized by category.
- **[Download the OpenAPI v2 Specification (`/apis/v2.yml`)](/apis/v2.yml)** — Import this file directly into [Postman](https://www.postman.com/), [Insomnia](https://insomnia.rest/), or OpenAPI code generators.
- **[Get started with the MCSS API](/API/about)** — Step-by-step guide to enabling the API and creating your first API key.

## Older API versions (Legacy)

If you are maintaining an older MCSS installation and cannot update yet, use the legacy references below:

- **[API v1 Reference (MCSS 13.0 – 13.8)](/apis/v1)** and **[OpenAPI v1 Specification (`/apis/v1.yml`)](/apis/v1.yml)** — Legacy API used prior to MCSS 13.9.0.
- **[MCSS v12 Postman Documentation](https://documenter.getpostman.com/view/7749159/TzJsexSC)** — External documentation for MCSS version 12.
