---
title: "Move an MCSS installation"
description: "Move MCSS and all of your servers to a new folder, drive, or Windows computer."
---

Because MCSS keeps its application settings and default `servers` folder inside its own directory, moving your entire MCSS setup to another folder, drive, or computer is straightforward.

<Callout type="info">
If you only want to bring a single standalone Minecraft server into an existing MCSS setup, use [Import an existing server](/basic/import-server/supported-server-files) instead. Follow this guide when moving your whole MCSS installation and all of its settings together.
</Callout>

## 1. Stop your servers and close MCSS

1. Stop all running servers in MCSS and wait until every server status shows **Offline**.
2. Click **File → Exit** in the top menu to close MCSS completely (clicking the window's `X` button may minimize MCSS to the system tray depending on your settings).

## 2. Copy the MCSS folder

1. Copy your entire MCSS installation folder—including `mcss.exe`, the `resources` folder (which stores `mcss_config.json`), and the `servers` folder—to the new folder, drive, or computer.
2. Keep your original folder intact as a backup until you have verified that everything runs smoothly in the new location.

## 3. Check paths on the new location or computer

If you moved MCSS to a **different computer** or changed drive letters, check these settings after opening the new `mcss.exe`:

- **Java installations:** Make sure the [required Java versions](/advanced/java-version) are installed on the new computer. If you configured a [global](/advanced/java-path-update#-globally) or [per-server Java path override](/advanced/java-path-update#-per-server) (or hardcoded a Java path inside a `.bat` file), update it if the path to `java.exe` changed.
- **Backup destinations:** Open each server's **Backups** tab and edit your backup templates to make sure the **Destination** folder path exists on the new drive or computer.
- **Networking and firewall (new computer only):** If you moved to a new PC, update your [Windows Firewall rules](/networking/windows-firewall) and your router's [port forwarding rule](/networking/port-forwarding) to point to the new computer's LAN IPv4 address.

## 4. Start and verify

Launch `mcss.exe` from the new folder, confirm all of your servers appear in the list, and start a server to verify that it boots cleanly and loads your worlds. Once everything is working, you can archive or remove the old copy.
