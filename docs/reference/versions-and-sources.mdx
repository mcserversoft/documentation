These guides target **MCSS 13.10.0**. MCSS is version agnostic; game software, loaders, plugins/mods, and Java have their own version requirements.

Minecraft's **26.x** release numbers are part of its newer numbering scheme, not Java version numbers. For example, Minecraft 26.1 introduced Java 25. Do not choose Java merely by matching the number in the game's name.

## What to check for a new release

Read the exact server/pack release's Java requirement, loader build, and update instructions. Check whether the plugins/mods you need have compatible builds. Review world-format changes and test a [restorable backup](/backups/backup-and-restore) before upgrading.

A screenshot can show an older game version while still illustrating an MCSS control. Use your installation's actual filenames, paths, and ports, not those captured in an old image.
