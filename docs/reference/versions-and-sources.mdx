## Java runtimes (64-bit OpenJDK)

Different Minecraft releases require different versions of Java. If you aren't sure which Java version your server needs, check our [Java version guide](/advanced/java-version).

| Java distribution | Official download page |
| --- | --- |
| **Eclipse Temurin (Adoptium)** *(recommended)* | [adoptium.net/temurin/releases](https://adoptium.net/temurin/releases/) |
| **Microsoft Build of OpenJDK** | [learn.microsoft.com/java/openjdk/download](https://learn.microsoft.com/en-us/java/openjdk/download) |
| **Oracle Java SE / JDK** | [oracle.com/java/technologies/downloads](https://www.oracle.com/java/technologies/downloads/) |

> [!TIP]
> **Minecraft `26.x` vs. Java version numbers**
> Starting in 2026, Minecraft moved to year-based version numbers such as **Minecraft 26.1**. Note that the `26` in Minecraft `26.1` refers to the year 2026, not Java 26—Minecraft 26.1 and newer run on **Java 25**.

## Minecraft server software

See [Choose server software](/basic/supported-server-types) if you are deciding between Vanilla, plugins (Paper), or mods (Fabric, Forge, NeoForge).

| Server software | Best for | Official download & docs |
