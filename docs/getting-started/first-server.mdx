---
title: "Run your first server"
description: "Start a Vanilla or Paper Java Edition server locally before opening it to the internet."
---

This walkthrough is for a new **Vanilla or Paper Java Edition** server. For mods, use the [Fabric](/basic/create-server/Fabric/create-fabric-server-manually), [Forge](/basic/create-server/Forge/create-forge-server-manually), [NeoForge](/basic/create-server/NeoForge/create-neoforge-server), or [modpack](/basic/create-server/Forge/create-a-server-with-a-modpack) guide instead.

## 1. Prepare the files

1. Download MCSS from [mcserversoft.com](https://www.mcserversoft.com/) and follow the instructions supplied with **13.10.0**.
2. Choose a stable Minecraft release and download its [Vanilla or Paper server JAR](/basic/create-server/sourcing-server-file).
3. Install the [Java version required by that build](/advanced/java-version). For example, the current 26.x family uses Java 25; 1.21.x uses Java 21.

Keep your server in its own folder. Do not use your Minecraft client's installation directory as a server directory.

## 2. Create the MCSS server

In MCSS, open **File → New Server** and select the downloaded server JAR. Complete the creation dialog for your server, then review the [server execution settings](/basic/server-settings/accessing-server-settings).

Confirm the launcher filename and [Java executable](/advanced/java-path-update). Set an initial memory allocation that leaves room for Windows and other applications. A small test server is a useful baseline; increase its memory when the workload justifies it.

## 3. Complete the first start

Start the server and read its console output. On the initial run, Minecraft may create `eula.txt` and exit until you accept its terms.

Read the [Minecraft EULA](https://www.minecraft.net/en-us/eula). If you agree, edit the generated file while the server is stopped:

```properties
eula=true
```

Start again. Wait for the server to report that startup is complete; a process appearing in MCSS is not enough to prove that the game is ready. If startup fails, use [Startup errors](/troubleshooting/startup).

## 4. Join from the same computer

Open the matching Minecraft **Java Edition** client. In **Multiplayer → Direct Connection**, enter:

```text
localhost:25565
```

Use your actual game port if you changed it. `25565` is the normal Java game port; it is separate from the MCSS web panel/API port.

Once you can join, stop the server normally and create your first [backup](/backups/backup-and-restore).

## 5. Decide who needs access

- **Only you, on this computer:** keep using `localhost`.
- **Other devices at home:** use the server computer's [LAN address](/networking/find-ip), with an appropriate firewall rule.
- **Players outside your network:** configure [port forwarding](/networking/port-forwarding) or a [game tunnel](/advanced/using-playit.gg-with-mcss).

For a failure at any stage, follow the [local → LAN → internet test sequence](/networking/troubleshooting).

The download and Java steps follow [Mojang's server instructions](https://www.minecraft.net/en-us/download/server) and [Paper's setup guide](https://docs.papermc.io/paper/getting-started/).
