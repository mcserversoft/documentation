## 2. Install Java on Windows

1. Download the required version from [Eclipse Temurin](https://adoptium.net/temurin/releases/) using the links in the tables above.
2. Choose **Windows x64** and download the `.msi` installer (choose the **JRE** release if available; for Java 16, download the **JDK** installer).
3. Run the installer and finish the setup.
4. Open a **new** Command Prompt and check your default Java version:

```cmd
java -version
where java
```

## 3. Assign Java in MCSS

<Callout title="Running multiple servers with different Java versions" type="info">
If you run multiple servers that require different Java versions, follow the [Java path guide](/advanced/java-path-update) to configure a separate Java installation for each server.
</Callout>

* In MCSS, set the Java path in server settings or via the [global](/advanced/java-path-update#-globally) or [per-server Java override](/advanced/java-path-update#-per-server).
* If your server uses a [batch script (`run.bat`)](/advanced/java-path-update#if-the-server-uses-a-batch-file), make sure the script points to the correct Java executable if your system default is different.
* After changing Java, restart the server and check the console logs to confirm it starts with the correct runtime.
