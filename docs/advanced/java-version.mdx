Choose Java for the **server software you are starting**, not for MCSS itself. Different servers on one computer can use different Java installations.

## Vanilla and Fabric: current version families

| Minecraft Java Edition | Java baseline |
| --- | --- |
| **26.1–26.3** | **Java 25** |
| **1.20.5–1.21.11** | **Java 21** |
| **1.18–1.20.4** | **Java 17** |
| **1.17–1.17.1** | **Java 16** |
| **1.12–1.16.5** | **Java 8**; check the exact loader or modpack requirements. |
| Earlier versions, snapshots, or releases not listed here | Follow that release's instructions; do not infer a requirement from its version number. |

These ranges describe Minecraft runtime transitions. A server fork or modpack can require a different supported runtime. In particular, **Paper's recommendations differ for older versions**.

Minecraft changed to Java 21 in [1.20.5](https://www.minecraft.net/en-us/article/minecraft-java-edition-1-20-5) and Java 25 in [26.1](https://www.minecraft.net/en-us/article/minecraft-java-edition-26-1). Fabric's [current Java installation guide](https://docs.fabricmc.net/players/installing-java/windows) also covers Java 25. Historical transitions are documented in [Fabric’s Minecraft 1.17 transition notes](https://fabricmc.net/2021/05/27/117-for-developers.html) and the [1.18 prereleases](https://www.minecraft.net/en-us/article/minecraft-1-18-pre-release-2).

## Paper and other distributions

Paper currently recommends:

| Paper version | Recommended Java |
| --- | --- |
| 26.1 and newer published builds | 25 |
| 1.20–1.21.11 | 21 |
| 1.17–1.19 | 17 |
| 1.16.5 | 16 |
| 1.12–1.16.4 | 11 |
| 1.7.10–1.11 | 8 |

Check the [Paper requirements](https://docs.papermc.io/paper/getting-started/) for the build you download. For Forge, NeoForge, a proxy, or a modpack, use that project's release instructions. Do not assume that installing the newest Java will make every older pack work.

## Install on Windows

1. Download the required major version from [Eclipse Temurin](https://adoptium.net/temurin/releases/) or the [Microsoft Build of OpenJDK](https://learn.microsoft.com/en-us/java/openjdk/download).
2. Choose a build matching the server computer's architecture. For an ordinary 64-bit Intel/AMD Windows machine, choose **Windows x64**. A JDK includes the runtime needed to launch a server; you do not have to find a separate JRE download.
3. Run the installer or extract the ZIP, following the provider's instructions. Note where it puts `bin\java.exe`.
4. Open a **new** Command Prompt and check:

```cmd
java -version
where java
```

`java -version` checks the Java found through `PATH`. It does not prove that an MCSS override or a batch file uses the same executable. Verify the actual executable too, using your installation path:

```cmd
"C:\path\to\your-jdk\bin\java.exe" -version
```

See [Adoptium's Windows installer instructions](https://adoptium.net/installation/windows/) for installation options.

## Assign Java to your server

Use MCSS's [global or per-server Java override](/advanced/java-path-update). If a batch file starts the server, inspect the executable in that file as well.

After changing Java, stop and start the affected server, then check its startup output. Keep older Java installations only where you still need them, and keep the selected major version patched.

*Version requirements checked on 15 October 2026. For a newer game or server release, consult its own release notes before upgrading.*
