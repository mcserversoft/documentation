---
title: "Choose server software"
description: "Compare Vanilla, Paper, mod loaders, proxies, and Bedrock to pick the right software for your server."
---

Before creating a server in MCSS, decide what kind of Minecraft experience you want to host. Because MCSS is version agnostic, you can run any of the server types below—your choice determines which game edition can join, which [Java version](/advanced/java-version) you need, and whether you can add plugins or mods.

## Vanilla Java Edition [#-vanilla-minecraft]

Download the Vanilla server JAR from [Mojang's website](https://www.minecraft.net/en-us/download/server) for the standard Java Edition server experience. It does not support Bukkit/Paper plugins or Forge/Fabric mods.

Players must use the same Minecraft version on their computer as the server. If this is your first server, pick a stable release rather than an experimental snapshot.

## Servers with plugins [#-plugin-support]

**Plugins** add server-side features—like land claiming, economy systems, or grief prevention—without requiring players to install anything on their own computers.

<Callout title="Not sure which to pick?">
Start with **Paper**. It is the modern community standard: fast, stable, and compatible with almost every plugin available.
</Callout>

| Software | Best for… | Why choose it? | Official source |
| --- | --- | --- | --- |
| **Paper** *(Recommended)* | Most servers | Dramatically improves server performance (reduces lag), fixes vanilla exploits, and runs almost all Spigot and Bukkit plugins. | [Paper](https://papermc.io/downloads/paper) |
| **Purpur** | Customizing gameplay | Built on top of Paper, adding hundreds of optional settings to tweak mob behavior, villager mechanics, and game rules (like riding any mob) without needing extra plugins. | [Purpur](https://purpurmc.org/) |
| **Spigot / CraftBukkit** | Legacy setups | Older software that Paper is built upon. Only choose these if an older or niche plugin explicitly refuses to run on Paper. | [Spigot BuildTools](https://www.spigotmc.org/wiki/buildtools/) |

When downloading plugins, always check that they support your Minecraft version. See [Installing plugins and mods](/running/plugins-and-mods) for step-by-step instructions.

## Servers with mods [#-modded-servers]

**Mods** change the game fundamentally—adding new items, dimensions, machinery, and creatures. Because mods alter the core game, **every player who connects must have the exact same mods installed** on their computer as the server.

<Callout title="Important" type="warn">
Mod loaders are mostly **not** interchangeable. If a mod is made for Fabric, it will not work on Forge or NeoForge. Always follow the mod author's instructions.
</Callout>

| Loader | Best for… | What you need to match | Official source |
| --- | --- | --- | --- |
| **Fabric** | Lightweight, performance-friendly mods; very popular for modern versions. | Minecraft version, Fabric Loader version, and any required helper mods (dependencies). | [Fabric guide](/basic/create-server/Fabric/create-fabric-server-manually) |
| **Forge** | Large, traditional content and overhaul mods (classic modpacks). | Minecraft version and the *exact* Forge build requested by the modpack. | [Forge guide](/basic/create-server/Forge/create-forge-server-manually) |
| **NeoForge** | Modern continuation of Forge; widely used by newer community modpacks. | Minecraft version and the *exact* NeoForge build requested by the modpack. | [NeoForge guide](/basic/create-server/NeoForge/create-neoforge-server) |
| **Quilt** | Alternative mod loader built off of Fabric; community-driven. | Loader and Minecraft versions explicitly stated by the mod author. | [Quilt installer](https://quiltmc.org/en/install/server/) |

* **If you are installing a pre-made modpack:** Always download the official **server pack** provided by the pack author rather than trying to build it piece-by-piece. See [How to install a modpack server](/basic/create-server/Forge/create-a-server-with-a-modpack).
* **Cross-loader rule:** Do not substitute Forge for NeoForge; Fabric and Quilt mods are also not interchangeable unless the mod author states otherwise.

## Proxies and cross-play [#-proxy--network]

* **Proxies ([Velocity](https://papermc.io/software/velocity) & [BungeeCord](https://www.spigotmc.org/wiki/bungeecord/)):** A proxy acts like a digital lobby or reception desk—it connects players to multiple backend worlds (like a Survival server and a Minigame server). **A proxy is not a world server by itself;** you must run backend servers alongside it.

<Callout>
**Waterfall is discontinued.** If you need a proxy, use [Velocity](https://papermc.io/software/velocity) (recommended by PaperMC). Check [PaperMC's proxy comparison](https://docs.papermc.io/velocity/comparisons-to-other-proxies/) for more details.
</Callout>

* **Geyser (Bedrock Cross-Play):** [Geyser](https://geysermc.org/wiki/geyser/setup/) allows players on consoles, phones, and Windows Bedrock editions to join a Java server. Note that Geyser is a translation tool, not an ordinary Java proxy or mod loader.

<Callout title="Network warning" type="warn">
Regular Java servers use TCP ports, but Geyser's Bedrock listener requires UDP ports open as well.
</Callout>

## Bedrock Dedicated Server [#-bedrock-server]

Choose this if you want to host a world exclusively for **Bedrock Edition** players (mobile, console, and Windows Bedrock):

* **No Java required:** Unlike Java Edition servers, Mojang's official [Bedrock Dedicated Server](https://www.minecraft.net/en-us/download/server/bedrock) runs as a standalone program (a `.exe` on Windows), not a `.jar` file. You do not need Java installed.
* **Bedrock players only:** Java Edition players cannot connect, and Java plugins or mods (Paper, Forge, Fabric) are not supported. Customization is handled through Bedrock Add-Ons (Behavior and Resource packs).
* **Network difference (UDP):** Bedrock connections use **UDP port 19132** by default (unlike Java servers, which use TCP port 25565).
* **Setup:** Download and extract the full `.zip` package from Mojang into your server folder, then point MCSS to the extracted executable.

<Callout title="Want Java and Bedrock players to play together?">
Do not use Bedrock Dedicated Server for cross-play. Instead, host a Java server (like Paper) and install [Geyser](#-proxy--network) so Bedrock players can join it.
</Callout>
