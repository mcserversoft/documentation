## Identify what you are downloading [#-getting-a-server-file]

A download may be a runnable server JAR, an installer, a native executable, or a complete server pack. These need different startup commands.

| Download | What to do next |
| --- | --- |
| Vanilla or Paper server JAR | Create a server with that JAR, then complete the first start. |
| Fabric executable server launcher | Use the launcher JAR; retain the files it creates. |
| Forge / NeoForge installer | Install a server first, then use its generated launcher and libraries. |
| Modpack server archive | Extract the whole pack and follow its instructions. |
| Bedrock Dedicated Server archive | Extract the complete package and use its server executable. |

Do not choose an installer as the permanent game launcher. A loader's `universal` JAR or development kit is not necessarily a runnable server either.

Select an **exact Minecraft version**, then a compatible server build. Keep the download's real filename visible in Windows File Explorer so you do not accidentally use `server.jar.jar` or a downloaded HTML error page.

For an older Vanilla version that is not on the current download page, use the server download associated with that version in the official Minecraft Launcher when available. Avoid repackaged executables and third-party server download mirrors.
