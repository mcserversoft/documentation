Before creating a server in MCSS, you need to download the official server software.

<Callout title="Not sure which software you need?">
If you haven't decided whether to use Vanilla, Paper, Fabric, Forge, or Bedrock, read our guide on **[Choosing server software](/basic/supported-server-types)** first.
</Callout>

## 1. Understand what you are downloading [#-getting-a-server-file]

Not all server downloads work the same way. Depending on the software you pick, you will receive one of three file types:

| File Type | Examples | What to do with it |
| --- | --- | --- |
| **Direct Server JAR** | Vanilla, Paper, Purpur, Fabric | **Ready to run.** Select this `.jar` file directly in MCSS when creating your server. |
| **Server Installer** | Forge, NeoForge | **Requires installation first.** Run the installer to generate your server files and libraries. *Never select the installer `.jar` as your main server file in MCSS.* |
| **Zip Archive** | Bedrock Dedicated Server, Modpacks | **Must be extracted.** Unzip the entire archive into your server folder, then select the extracted executable or launch file. |

<Callout title="Common beginner mistake" type="warn">
If you download a **Forge** or **NeoForge installer**, do not choose it as your permanent server JAR in MCSS. You must install the server files first, then select the launcher that the installer creates.
</Callout>

## 3. Important tips for beginners

* **Make file extensions visible in Windows:** Windows hides extensions like `.jar` or `.zip` by default. In Windows File Explorer, enable file extensions (click **View → Show → File name extensions**). This prevents mistakes like naming a file `server.jar.jar`.
* **Match client and server versions:** Your players' Minecraft version must match your server version (e.g., a 1.21 client cannot join a 1.20 server without compatibility plugins like ViaVersion).
* **Older Vanilla versions:** If you need an older Vanilla release not featured on the main download page, download it through the official Minecraft Launcher by creating an installation profile for that version.
* **Keep your server in its own folder:** Always give each server its own dedicated folder. Never download or run server files directly on your desktop or inside your Minecraft client installation.
