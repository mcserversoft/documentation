title: "Forge with the MCSS installer"

MCSS provides a Forge/Fabric installer workflow, also listed on the [official MCSS website](https://www.mcserversoft.com/). This page covers the Forge workflow. You can instead [install Forge manually](/basic/create-server/Forge/create-forge-server-manually).

For a published modpack, use its [server pack instructions](/basic/create-server/Forge/create-a-server-with-a-modpack) first.

## Choose the installer [#-download-forge]

Select the exact Minecraft version and Forge build required by your mods. MCSS's version independence does not make mods for different loaders or Minecraft releases compatible.

### Download Forge [#-download-forge-installer]

Get the **Installer** from [Forge's official download site](https://files.minecraftforge.net/). Do not substitute a source archive, development kit, or unrelated JAR. Install the [Java version required by your selected release](/advanced/java-version).

## Create the MCSS server [#-create-the-forge-server]

In the server creation dialog, select the downloaded Forge **installer** in the **Server File** section.

![Selecting a Forge installer in MCSS](/img/docs/create-forge/forge_installer.png)

## Wait for installation [#-let-the-installer-do-its-job]

MCSS runs installation in the background. Wait for it to finish and check any error output before starting the game server. Installation can need internet access to download libraries.

![Forge installation progress in MCSS](/img/docs/create-forge/forge_installer_busy.png)

## Review the launcher [#-tweaking-the-server-start-settings]

Open the resulting server folder and inspect what the installer generated.

- Older Forge installations may have a directly runnable Forge JAR. Match its filename to the configured startup line. The older MCSS preset documented here used `forge.jar`.
- Forge 1.17 and later commonly uses a generated `run.bat` plus argument files and `libraries`. In **Advanced**, select **Use Bat file** and the generated launcher.

![Batch launcher selection in MCSS](/img/docs/create-forge/forge_incorrect_server_settings.png)

Use the [manual Forge guide's launch checks](/basic/create-server/Forge/create-forge-server-manually#-migrate-the-server-to-mcss) for the batch file: choose the correct Java, remove an interactive `pause`, retain the generated argument paths, and add `nogui` where the server launcher accepts it.

Finish the [first-start EULA step](/getting-started/first-server#3-complete-the-first-start), then join locally using a client with the matching Forge version and required mods. The screenshots illustrate the interface with older Forge examples; use your downloaded release's filenames.
