## Two kinds of settings [#-mcss-handle-settings]

MCSS organizes server configuration into two separate areas:

* **Minecraft settings:** In-game world and gameplay options (like difficulty, game mode, view distance, and the server MOTD).
* **Server execution settings:** How MCSS launches, monitors, and manages your server process (like RAM allocation, Java version, startup script, and crash recovery).

Always stop the server before changing its Java version, launcher file, memory allocation, or configuration files, then click **Save** so your changes apply on the next start.

## Minecraft settings [#-mcss-minecraft-settings]

Open the **Settings** tab on your server's dashboard to quickly edit common `server.properties` options such as difficulty, game mode, view distance, and MOTD.

![Minecraft settings pane in MCSS](/img/docs/server-settings/minecraft-settings.jpg)

If you need to edit a property that isn't shown in the visual form (or a setting specific to Paper, Purpur, or a mod), see [Server properties](/running/server-properties) to edit the configuration file directly.

## Server execution settings [#-mcss-server-execution-settings]

To open execution settings, click the **cogwheel icon** on your server dashboard or go to **Server → Edit Server**.

This opens the **Edit Server** window, which is divided into **General**, **Advanced**, **Crash Handling**, and **Update Server** sections.

### General [#-mcss-settings-general]

Use **General** to configure your server's display name, description, MCSS icon, RAM allocation, game port, and autostart behavior. Click **Save** when finished.

[![MCSS 13.10.0 General server settings, including RAM, port, save-all, and autostart](/img/docs/server-settings/general-13-10-0.png)](/img/docs/server-settings/general-13-10-0.png)

* **Force 'save-all' on server stop:** Tells MCSS to send a `save-all` command before stopping the server. Always wait for the server status to reach **Offline** before copying or editing world files.
* **Server icon:** The icon selected here is used inside the MCSS dashboard and web panel (your in-game server list icon is still controlled by `server-icon.png` in the server folder).
* **RAM and Port:** Changes to memory or port take effect the next time you start the server. If you run multiple servers at once, give each server its own unique port.

### Advanced [#-mcss-settings-advanced]

Use **Advanced** to choose your server's Java path, custom Java startup line, or `.bat` launcher file.

[![MCSS 13.10.0 Advanced settings with local Java override, Startup Line, and Use Bat file](/img/docs/server-settings/advanced-13-10-0.png)](/img/docs/server-settings/advanced-13-10-0.png)

* **Java Path:** Select the [Java version your server needs](/advanced/java-version), or leave it on the global MCSS Java path if all your servers use the same runtime.
* **Startup Line:** Controls the Java command MCSS runs for single-JAR servers. The `[RAM]` placeholder automatically inserts the memory value from the **General** tab (`-Xmx[RAM]M`).
* **Use Bat file:** Used by modern Forge, NeoForge, and modpack servers that launch through a script like `run.bat`. When using a batch file, set your RAM inside the script or its `user_jvm_args.txt` file, and remove any interactive `pause` statement as shown in the [Forge batch-launcher guide](/basic/create-server/Forge/create-forge-server-manually#review-a-generated-batch-launcher).

If you have a long list of custom JVM flags, **Startup Line** can also pass a Java argument file (such as `java @launch.args`), where `launch.args` is a text file in your server folder containing your JVM flags and `-jar` target:

[![MCSS 13.10.0 Startup Line configured to read a Java argument file](/img/docs/server-settings/argument-file-startup-13-10-0.png)](/img/docs/server-settings/argument-file-startup-13-10-0.png)

When using a custom script or [modpack launcher](/basic/create-server/Forge/create-a-server-with-a-modpack#-step-2), let MCSS handle restarts rather than adding an infinite restart loop inside the `.bat` file.

### Crash handling / Keep Online [#-mcss-settings-crash]

The **Crash Handling** tab controls whether MCSS automatically restarts your server if it stops unexpectedly:

| Mode | Behavior |
| --- | --- |
| **Nothing** | Never restarts automatically after a stop or crash. |
| **Elevated** | Automatically restarts the server if it crashes or stops outside of MCSS, while staying offline when you click **Stop** in MCSS. |
| **Aggressive** | Restarts the server whenever it stops for any reason (note: this can conflict with scheduled tasks and backups). |

[![MCSS 13.10.0 Crash Handling descriptions for Nothing, Elevated, and Aggressive](/img/docs/server-settings/crash-handling-13-10-0.png)](/img/docs/server-settings/crash-handling-13-10-0.png)

<Callout title="Tip for server maintenance">
If you are troubleshooting a server that crashes immediately on startup, or performing manual file maintenance, set Crash Handling to **Nothing** (or **Elevated** when stopped via MCSS) so the server does not try to restart while you are working on it.
</Callout>

### Update Server [#-mcss-settings-update]

The **Update Server** section lets you quickly replace the server `.jar` file for single-JAR servers (such as Vanilla or Paper). Always stop the server and take a [backup](/backups/backup-and-restore#take-a-consistent-manual-backup) before updating.

For modded servers (Forge, NeoForge, or modpacks) that also update libraries and launch files, follow the full [server update guide](/running/updating).
