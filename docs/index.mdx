Welcome to the **MC Server Soft (MCSS)** documentation! MCSS is a dedicated server manager for Windows that makes it easy to create, configure, monitor, and automate your Minecraft servers from a clean desktop interface or web panel.

These guides cover **MCSS 13.10.0**. Because MCSS is **version agnostic**, you can run almost any Minecraft version or server software—from a simple Vanilla survival world for friends to a modded Forge, Fabric, NeoForge, or Paper server.

## How the pieces fit together [#-introduction]

When you host a Minecraft server on your computer, four parts work together:

| Component | What it does |
| --- | --- |
| **MCSS** | Starts, stops, and monitors your servers, and provides tools like backups, scheduled tasks, a web panel, and an API. |
| **Minecraft server software** | Runs the game world itself and loads your chosen plugins or mods (such as Vanilla, Paper, Fabric, or Forge). |
| **Java** | Runs Java Edition server software. (Bedrock Dedicated Server runs as its own Windows `.exe` program and does not need Java.) |
| **Your network** | Connects players to your server—whether on the same PC, across your home Wi-Fi/LAN, or over the internet. |

## Before you start [#-pre-requisites]

1. Download MCSS from [mcserversoft.com](https://www.mcserversoft.com/).
2. Choose your [server software](/basic/supported-server-types) (we recommend **Paper** or **Vanilla** for your first server).
3. Install the [required Java version](/advanced/java-version) for your chosen Minecraft release.
4. Make sure your computer has enough free memory (RAM) and disk space for your world and backups.

<Callout title="Playing locally first">
You do **not** need port forwarding to test your server on the same computer or play with family on your home network. Get your server running locally first, then set up [internet access](/networking/port-forwarding) when you are ready to invite outside friends.
</Callout>

## Existing and older installations [#-pre-requisites-older-versions]

### MCSS 13 installations [#-pre-requisites-v13]

Follow the prerequisites included with your MCSS download. If Windows reports a missing runtime or DLL when opening the app, see [Missing Scintilla or Visual C++ runtime](/troubleshooting/mcss-and-windows#missing-scintilla-or-visual-c-runtime).

### MCSS 12 and earlier [#-pre-requisites-v12]

Older versions of MCSS use different dependencies and settings formats. Before upgrading from an older release, check the [official changelogs](https://www.mcserversoft.com/changelogs) and keep a backup copy of your existing MCSS folder and servers.
